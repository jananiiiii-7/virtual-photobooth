🎥 Virtual Photobooth
A browser-based photobooth experience with customizable photo strips, frames, and creative features.


🚀 Features

Live webcam preview.
Capture snapshots instantly.
Save multiple photos into a gallery.
Download snapshots as images.
(Planned) Choose from layouts — Polaroid, 3-strip, 4-strip.
(Planned) Reorder photos and retake specific shots.
(Planned) Add custom frames, stickers, and text.
(Planned) “Design your own frame” feature.
(Planned) Integration into a collaborative scrapbook project.

🛠️ Tech Stack

HTML5 – structure.
CSS3 – layout and basic styling.
JavaScript (ES6) – core functionality.
Canvas API – capture and manipulate snapshots.

🎯 Future Improvements

Multiple themed frames (retro, modern, festive).
User-created frames with drawing tools.
Stickers, handwriting, and message overlays.
Export full photo strips as downloadable images.


💡 Inspiration

Inspired by classic photo booths and the idea of turning memories into interactive, customizable digital experiences.
